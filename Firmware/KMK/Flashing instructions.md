# Flashing instructions

---

To install KMK based firmware on out nice!nano MCU, follow the steps mentioned below:

1. Plug in your Type-C cable into your nice!nano MCU then connect it with your PC.
2. nice!nano will appear just like a USB.
3. Install Circuitpython from ```https://circuitpython.org/board/nice_nano/``` for nice!nano.
4. The downloaded file will be .UF2 formate based.
5. Drag and drop the downloaded .UF2 file onto the nice!nano USB, it will automatically install circuitpython on nice!nano, then i'll auto eject it self and appear as circuitpython USB.
6. Copy-Paste your Kmk firmware ```code.py``` file into the circuitpython USB.
7. Then press the Reset button, it'll reset the MCU.
8. Your Keyboard should be functional after following the above steps.
